PrepAtoZ - GitHub and Netlify
===========================

Local preview: npm start, then http://127.0.0.1:4173
Publish folder: dist
Build command: npm run check
Node version: 22
Routing: hash-based, so no SPA catch-all redirect is required.

Netlify deployment
------------------
1. Connect the existing prepatoz project to shasanksingh/PrepAtoZ, branch main.
   Keep this GitHub repository private. The website's general library may be public.
2. Use netlify.toml: publish directory dist, functions directory netlify/functions,
   Node 22 and build command npm run check. Do not publish the repository root.
3. Follow ACCOUNT-SETUP.txt to connect persistent cloud SQLite-compatible storage
   and configure the reserved administrator account through Functions env vars.
4. Redeploy and confirm public learning works without signing in, a regular
   account cannot open /api/admin/content, and the admin can open its vault.
5. Delete or restrict previous Netlify deploy snapshots that contain the old
   public project data. Protecting this release cannot erase previously shared
   files or make old deployment URLs private automatically.

Do not use a static-only drag-and-drop deployment for accounts: it cannot deploy
the server API or access-control functions. The refreshed companion ZIP contains
only safe public static files for guest-only use; it does not contain private
content, credentials or a login backend. Deploy the GitHub project for accounts.
No live Netlify or database credentials are committed to this repository.

Source docs:
https://docs.netlify.com/manage/security/secure-access-to-sites/project-visibility/
https://docs.netlify.com/configure-builds/overview/
